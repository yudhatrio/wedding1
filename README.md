# Struktur Undangan

Struktur:
- `index.html` — isi/teks undangan (komentar penanda tiap slide)
- `css/style.css` — desain & animasi
- `js/script.js` — countdown (`TANGGAL_ACARA`), musik, navigasi, slider foto
- `assets/img/` — gambar (ganti file dengan nama sama untuk mengganti foto; `foto-4.jpg` & `foto-5.jpg` masih contoh)
- `assets/audio/musik.mp3` — musik (sudah dipotong, dimulai dari detik ke-34 lagu asli, diputar berulang)

Jalankan di GitHub Pages: push semua isi folder ke repo, lalu Settings → Pages → pilih branch `main` / root.
